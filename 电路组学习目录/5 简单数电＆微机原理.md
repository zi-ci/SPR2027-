### 5.1 开漏输出&推挽输出&三态输出
- 数字信号指的是只有0与1的信号，高低电平代表逻辑上的0与1，是离散的信号，比如规定高于2.4V就是1，低于0.7V就是0，那么信号处于0.7V和2.4V之间不高不低的状态是不被允许的，因为这种状态不能确定到底是数字1还是0，我们管这种无法确定的状态叫做真空态。
- 数字电路（也称数电）为了能很好的输出数字信号，就要做到以下几点：\
第一，输出速率要尽可能的快速，要能够快速地开关。\
第二，输出电流的要尽可能的大，就可以更好的驱动下一级电路。\
第三，尽可能避免真空态，输出在01之间跳变的过程中不可避免的要经过短暂的真空态（电压高低切换的过程中会短暂经过不高不低的范围）。
- 为了做到上面三点，我们会使用推挽或者开漏输出作为数字电路的输出，如上图所示，为了更快的速率，现代的所有数字芯片（各种高速的逻辑芯片，单片机，FPGA，电脑，或者其它）内部都是使用mos管制作的，称为CMOS工艺。 \
![图5-1-1 开漏输出&推挽输出 ](pictures/5-1-1.png)
- 绝大多数都使用推挽输出，因为推挽输出不论输出高电平还是低电平，他的输出电阻都会很低，信号在01之间翻转的速率会更快。
- 数字芯片的开漏输出需要手动去添加上拉/下拉电阻，而推挽输出不需要，所以在挑选芯片设计电路的过程中一定要查阅手册看芯片的输出方式到底是推挽还是开漏。

[开漏输出与门数据手册（点击阅读）](datasheet/CMOS开漏输出与门芯片.pdf)\
![图5-1-2 推挽输出与门](pictures/5-1-2.png)
![图5-1-3 开漏输出与门](pictures/5-1-3.png)

- 比起在推挽输出中，还可以分出来一种叫做三态输出的输出方式，其电路如下图 \
![图5-1-4 三态输出与门](pictures/5-1-4.png)
- 三态输出本质上还是推挽输出，不过比起推挽输出只能输出高电平与低电平这两种状态，三态输出多出来一种输出状态，叫做高阻态，三态输出可以输出高电平，低电平，高阻，三种状态。
- 其等效的电路相当于在推挽输出前方增加了一个开关，开关由EN（enable）引脚控制。当EN输入高电平，开关开启时，电路相当于推挽电路。当EN输入低电平，开关关闭时，电路处于高阻态，电路的输出引脚相当于什么都没接，电压值完全由外部的其它电路控制。
- 高阻态时相当于这个电路失去了对导线的电压的控制权，让其它电路去控制。

- 我们管数字信号由低电平跳变到高电平的瞬间称为上升边沿，称信号由高电平跳变到低电平的瞬间称为下降边沿，上升边沿与下降边沿统称为边沿，如下图。 \

- 如果把上升和下降边沿放大，会变成如下图的样子 \
![图5-2-2 上升边沿放大](pictures/5-2-2.png)
![图5-2-3 下降边沿放大](pictures/5-2-3.png)
- 我们发现实际上的波形并不是很干净的方波，而是方波上升时会有一定的斜率，沿着斜率缓慢上升，而且会有微小的过冲和振荡。
- 波形变得如此难看的原因有以下三点：\
寄生电容，寄生电感，寄生电阻 \
第一：寄生电容，已知导线是由铜制成的，铜拥有一定的容纳电荷的能力（即使很小很小），所以铜导线相当于有一个很小很小的寄生电容，一般在pF的量级。\
第二：寄生电感，已知当导线有电流经过时，会围绕导线产生微小的磁场（也是很小很小），所以铜导线相当于一个很小很小的寄生电感，一般在nH级别。\
第三：寄生电阻，已知铜导线是有一定的电阻率的，铜制成的导线的阻值并非为0，铜导线有一个很小很小的寄生电阻，一般在mΩ级别。
- 如果画出拥有寄生电容，寄生电感，寄生电阻的导线的等效电路，就如下图所示 \
![图5-2-4 现实中的导线](pictures/5-2-4.png)
- 现实中的方波有两个问题，上升速率和过冲。\
过冲，是由寄生电容和寄生电感决定的，我们平时不用太在意，在非超高频的场景，这个并不会产生太大的影响。\
上升速率，是由寄生电容和寄生电阻决定的，参考电路原理章节提到的RC响应，我们可知RC的值越小，方波上升的速率越快，方波就越接近理想的方波。
- 在推挽输出中，输出高/低电平时输出相当于经过mos管跟供电相连，阻值很低，RC很小，上升很快。
- 在开漏输出中，高低电平的输出只有一种是经过mos管连到供电的，而另一种则是通过上下拉电阻连接到输出的，上下拉的阻值很大（一般是10k级别），RC的值很大，导致方波上升的速率很慢很慢。

### 5.3 施密特触发器
- 要规定0和1的电压范围，我们可以设置一个电压标准，比标准高就是高电平，比标准低就是低电平，比如设置标准为1.5V，那么高于1.5V的输入我们就能看作1，低于1.5V的输入就能看作0，写作数学公式就是 

```math
V_{out} = 
\begin{cases}
1~,&(u_{in}\geq 1.5V) \\
0~,&(u_{in}< 1.5V)
\end{cases}
```
这种规定看似不错，但在现实中极易受到噪声的影响，导致下面这种问题。
- 我们之前说到现实中任何的波形都是充满大量噪声干扰的（详见电路原理章节），如果使用上面的只有一个电压标准的判断方法，在遇到噪声时就会发生下图的现象 \
![图5-3-1 电平异常跳变](pictures/5-3-1.png)
- 上图蓝色曲线为输入波形（从0V跳变到5V的上升边沿，但是有很多噪声），橙色曲线为比较电压（这里是1.5V），黄色曲线为根据比较电压判断输出电平0还是1。
- 按理来说黄色曲线应该是从0跳变到1，但是图中黄色曲线先是在输入电压接近比较电压的时候来回跳变了若干次才变成高电平，这种来回跳变的现象是一个错误的信号，会产生很危险的后果。如果放大上图，得到下方的图片，我们可以看到产生跳变的原因。 \
![图5-3-2 电平异常跳变放大版](pictures/5-3-2.png)
- 前面提到输入信号的上升和下降边沿不是瞬间的，而是沿着一个斜率缓慢上升的，当输入信号缓慢上升到接近比较电压时，噪声会让输入信号在比较电压周围上下振荡，多次穿过比较电压的阈值，产生许多次误判，导致了错误信号的产生。
- 为了避免上面这种现象，我们会使用两个比较电压，叫做电压的上升阈值 $V_{T+}$ 和下降阈值 $V_{T-}$ ，当输入电压超过上升阈值时，输出变成1，当输入电压低于下降阈值时，输出变成0，当输入电压处于上升阈值和下降阈值之间时，输出保持之前的状态不变，如果写成数学公式就是

```math
V_{out} = 
\begin{cases}
1~,&(u_{in}\geq V_{T+}) \\
保持不变~,&(V_{T+}> u_{in}\geq V_{T-})\\
0~,&(u_{in}< V_{T-})
\end{cases}
```
这种触发方式叫做施密特触发，实现这种功能的电路叫做施密特触发器。
- 若是讲之前的充满噪声的波形输入给施密特触发器，得到的图像如下 \
![图5-3-3 施密特触发器处理上升沿](pictures/5-3-3.png)
- 新得到的输出波形十分干净，没有任何异常的跳变，施密特触发器可以实现对数字信号的抗干扰的作用。
- 施密特触发器的电路符号和现实中的封装如下 \
![图5-3-4 施密特触发器](pictures/5-3-4.png)
- 大多数施密特触发器芯片并不是输入高电平输出1，输入低电平输出0，而是反过来的输入高电平输出0，输入低电平输出1，所以有时也叫做施密特反相器。
- 施密特触发器常作为各种数字电路的输入整形电路，绝大多数的数字芯片内部都集成了施密特触发器，来让芯片的逻辑更稳定。
### 5.4 TTL电平与CMOS电平
- TTL和CMOS最初指的是两种不同的芯片工艺，如今TTL和CMOS演变出了新的含义，不再是指芯片的工艺，而是指芯片判断和输出0和1电压的两种不同的标准。
- 输入的上升阈值电压 $V_{IH}$ 表示输入的高电平 \
输入的下降阈值电压 $V_{IL}$ 表示输入的低电平 \
输出高电平 $V_{OH}$ ,输出低电平 $V_{OL}$ \
如上便是数字芯片输入输出电平的四个标准，输入输出满足下列关系 
```math
Logic = 
\begin{cases}
1~,&(u_{in}\geq V_{IH}) \\
保持不变~,&(V_{IH}> u_{in}\geq V_{IL})\\
0~,&(u_{in}< V_{IL})
\end{cases}
```
```math
V_{out} = 
\begin{cases}
V_{OH}~,&(逻辑1) \\
V_{OL}~,&(逻辑0)
\end{cases}
```
 
- TTL电平，常指的是5V的TTL电平，其输入输出的电平为 
```math 
\begin{aligned}
V_{OH} & \geq 2.4V ,\\
V_{OL} & \leq 0.4V ,\\
V_{IH} & \geq 2V ,\\
V_{IL} & \leq 0.8V
\end{aligned}
``` 
- CMOS电平，其电平标准会随着供电 $V_{CC}$ 而改变，其输入输出的电平为 
```math 
\begin{aligned}
V_{OH} & \approx V_{CC} ,\\
V_{OL} & \approx 0V     ,\\
V_{IH} & \geq 0.7V_{CC} ,\\
V_{IL} & \leq 0.3V_{CC}
\end{aligned}
``` 

- TTL电平是固定的，而CMOS的电平是随 $V_{CC}$ 而改变的，对于不同电平的信号，CMOS电平可以通过改变芯片的供电电压来实现对不同的电平的信号的兼容。
- 数字芯片的数据手册一般都会标注芯片的电平标准。
### 5.5 八种逻辑门，逻辑门的内部结构
- 在写代码时，经常会使用各种逻辑运算，比如C语言中
```c
    bool a = 1;
    bool b = 0;
    if( a && b ){/*codes*/} //满足条件a与b，就执行{/*codes*/}
```
- 诸如上面的“a && b“，就是一种逻辑运算，a和b是布尔值，只有0和1两种状态，表示真与假。a为1，b为0，那么a与b并没有同时满足，a与b的结果就是0，所以程序不会进入上面的if分支。
- 在原生的C语言中我们可以使用的逻辑运算有下面这些
```c
    bool a = 1, b = 1;
    bool and    = a && b;    // 与门：a 与 b
    bool or     = a || b;    // 或门：a 或 b
    bool not    = !a;       // 非门：非 a
```
- 在数字电路中，我们管能进行这些最基本的逻辑运算的电路叫做逻辑门，常见的逻辑门共有八种，他们的名称以及对应的逻辑式分别是: \
中继器 $S=A$ \
非门： $S=\overline{A}$ \
与门： $S=A \times B$ 或者 $AB$ \
或门： $S=A+B$ \
与非门： $S=\overline{A \times B}$ \
或非门： $S=\overline{A + B}$ \
异或门： $S=A \oplus B$ \
同或门： $S=A \odot B$ 
- 这八种逻辑门可以在电路层面进行与上面相同的逻辑运算。
- 逻辑运算的写法是每个逻辑门后面的逻辑式，通过逻辑式可以组合出各种各样的逻辑。
##### 缓冲器（中继器）＆非门（反相器）
- 缓冲器，又称中继器，一个输入，一个输出，输入与输出完全相同，输入0输出0，输入1输出1
- 非门，又称反相器，一个输入，一个输出，输入与输出完全相反，输入0输出1，输入1输出0

### 5.6 逻辑门的用法
![图5-6-1 八种逻辑门](pictures/5-6-1.png)
- 前面提到的八种逻辑门，可以组合出各种的逻辑电路，可分为组合逻辑和时序逻辑。
- 组合逻辑指输入和输出一一对应的电路，换言之就是没有记忆功能的电路，同样的输入一定会得到同样的输出，就像一个函数一样，输入一个 $x$ ，得到的结果一定是 $f(x)$ ，输入的时间，输入的顺序，都不会改变 $f(x)$ 这个函数本身。
- 时序逻辑指有记忆功能的逻辑电路，电路会记住之前进行过的输入，并根据之前的输入进行相应的动作，同样的输入，在不同的时间输入，结果可能不一样，比如输入第一个 $x$ ，得到了 $f(x)$ ，而第二次输入 $x$ ，得到的却是 $g(x)$ 。
### 5.7 组合逻辑
- 组合逻辑有一套完整的设计流程和方法，具体可查看数字电路的书籍，但我们并不太会用到，比起复杂的设计方法，我们只需要知道几个常见的电路即可。

#### 5.7.3 加/减法器
- 加法器是数字电路中最基本的运算电路，可以用逻辑门把两个二进制数相加。
- 最简单的是一位加法，我们管不考虑低位进位的加法器叫做半加器，它有两个输出：本位和 S 与向高位的进位 C。
```math
\begin{aligned}
S &= A \oplus B \\
C &= A \times B
\end{aligned}
```
- 把两个半加器和一个或门组合起来，就得到考虑进位输入的全加器。全加器有三个输入（两个加数 A、B，和低位进位 $C_{in}$），两个输出（本位和 S，高位进位 $C_{out}$）。
```math
\begin{aligned}
S &= A \oplus B \oplus C_{in} \\
C_{out} &= A \times B + (A \oplus B) \times C_{in}
\end{aligned}
```
- 把多个全加器串联起来（前一级的进位接到后一级的进位输入），就构成了能计算多位二进制加法的加法器。 \
![图5-7-5 半加器与全加器](pictures/5-7-5.png)
- 减法可以转换为加上一个负数来实现，而在二进制中用补码表示负数，所以减法器本质上还是加法器：$A-B=A+(-B)$，其中 $-B$ 用 B 的补码表示。

### 5.8 时序逻辑
- 前面讲的组合逻辑没有记忆能力，输出只取决于当前的输入。而现实中还需要能“记住”状态的电路，这就是时序逻辑。
- 时序逻辑的核心是时钟信号 CLK，它是一个周期性的方波，电路只在时钟的边沿（通常是上升沿）才对输入进行采样和更新，从而让整个电路按照统一的节奏工作。 \
![图5-8-1 时钟信号](pictures/5-8-1.png)
- 时序逻辑最基本的存储单元是触发器（Flip-Flop），常见的有 RS 触发器、D 触发器、JK 触发器等。其中 D 触发器最常用：在时钟上升沿把输入 D 的值锁存到输出 Q，其余时间 Q 保持不变。
```math
Q_{n+1} = D
```
- 有了能“记住”一位数据的触发器，再把它们组合起来，就能实现寄存器、计数器等各种各样的时序电路。
- 时序逻辑和组合逻辑的区别可以用一句话概括：组合逻辑的输出是“输入的即时函数”，时序逻辑的输出是“输入和过去状态的函数”。
#### 5.8.1 寄存器
- 寄存器就是由多个 D 触发器并排组成的，一个触发器存一位，n 个触发器就能存 n 位二进制数。 \
![图5-8-2 寄存器结构](pictures/5-8-2.png)
- 所有的触发器共用同一个时钟，在时钟上升沿同时把每一位输入锁存进去，在其它时间保持数据不变。
- 寄存器常用于暂存数据、保存中间计算的结果，CPU 内部的通用寄存器、外设的配置寄存器都是这种结构。
- 如果让寄存器里的数据每个时钟都往左或往右移动一位，就变成了移位寄存器，可以用来做串并转换、延时等。
- 如果让寄存器每个时钟自动加一，它就变成了计数器。
#### 5.8.2 定时器
- 定时器的本质就是一个会数数的计数器，它每来一个时钟脉冲就数一次、加一。 \
![图5-8-3 定时器原理](pictures/5-8-3.png)
- 如果用一个频率已知的时钟去驱动计数器，那么计数值就和时间一一对应，计到某个数就代表经过了固定的时间，这样就实现了定时。
- 例如时钟频率为 1MHz（每 1μs 一个脉冲），计数器数到 1000，就代表经过了 1ms。
- 计数器数满溢出后会自动回到 0 重新开始，或重新装载一个设定的初值（自动重装载），如此循环，就得到了周期性的定时信号。
- 定时器还能做很多事情：改变计数的上限可以得到不同频率的方波，用它可以产生 PWM 波来控制电机的转速、灯的亮度；记录两个外部事件之间计数了多少下，就能测量时间间隔。这也是定时器在单片机里同样重要的原因。

### 5.9 微机原理&了解STM32硬件结构
- 前面讲的都是一个个独立的数字电路模块，把它们按一定的方式组合起来、再加上存储器，就构成了一个能执行程序的微控制器（MCU），STM32 就是最常见的一类 MCU。
- 要会用 STM32，不能只会调用库函数，理解它内部的外设是怎么用数字电路实现的，才能在看手册、调 bug 的时候心里有数。
- 下面我们简单了解 STM32 内部几个最重要的硬件模块。
#### 5.9.1 GPIO硬件结构
- GPIO（General Purpose Input Output）是通用输入输出口，就是芯片上的那些引脚，可以配置成输入或输出。 \
![图5-9-1 GPIO硬件结构](pictures/5-9-1.png)
- 一个 GPIO 引脚内部并不只是一个 mos 管，而是一整套电路：输出部分有推挽/开漏的驱动电路，输入部分有施密特触发器和上下拉电阻，还有保护二极管等。
- 配置寄存器决定这个引脚是输入还是输出、是推挽还是开漏、要不要上拉，这些配置实际上就是在控制上面这些电路的开关。
- 前面章节讲的推挽、开漏、上下拉、施密特触发器，在 GPIO 里全都能见到，这也是为什么要先学这些基础。
#### 5.9.2 定时器硬件结构
- STM32 内部有多个定时器，它们的硬件结构可以简单看成：一个时钟源、一个预分频器、一个计数器、一个自动重装载寄存器，再加上比较/捕获电路。 \
![图5-9-2 定时器硬件结构](pictures/5-9-2.png)
- 时钟先经过预分频器分频，得到想要的计数频率；计数器在这个频率下不断累加；计数器的值可以和比较寄存器比较，相等时触发事件（比如翻转输出引脚，产生 PWM）；也可以把外部信号的边沿到来时的计数值捕获下来，用于测量时间。
- 定时器既能“定时”，又能“计数”，还能输出 PWM，是单片机里最万能的外设之一。
#### 5.9.3 两种RAM硬件结构
- 存储器分为易失性的 RAM 和掉电不丢失的 ROM（在 STM32 里是 Flash）。其中 RAM 又常见的分为两种：SRAM 和 DRAM。 \
![图5-9-3 SRAM与DRAM](pictures/5-9-3.png)
- SRAM 用多个 mos 管组成的触发器来存每一位数据，只要不断电数据就一直保持，不需要刷新，速度快，但每一位占的晶体管多、成本高。
- DRAM 用一个 mos 管加一个小电容来存一位数据，电容会漏电，需要不停地刷新来保持数据，结构简单、容量大、成本低，但速度慢一些。
- 单片机的片上 RAM 一般用 SRAM，因为容量小、要求快、不需要复杂的刷新电路；电脑的内存条则用 DRAM。
#### 5.9.4 时钟树硬件结构
- 时钟是数字电路的“心跳”，整个芯片的各个模块都要靠时钟来同步工作。 \
![图5-9-4 时钟树硬件结构](pictures/5-9-4.png)
- STM32 内部的时钟不是只有一个，而是从一个或几个时钟源出发，经过分频、倍频（PLL）、选择开关后，像树枝一样分配到各个外设，这套结构就叫做时钟树。
- 常见的时钟源有内部的 RC 振荡器（HSI）和外部的晶振（HSE）等，PLL 可以把低频时钟倍频到很高的频率，供 CPU 使用。
- 配置时钟树时，其实就是在设置这些分频/倍频系数和每个外设用哪个时钟源，这也是单片机初始化里最容易出错、又最需要理解的一部分。
#### 5.9.5 中断系统硬件结构
- 中断是指：CPU 正在执行主程序时，突然有个外设（比如定时器、串口、按键）发生了事件，它向 CPU 发出请求，CPU 暂停当前的工作，转去执行一小段专门处理这个事件的程序（中断服务函数），处理完再回到刚才暂停的地方继续执行。 \
![图5-9-5 中断系统结构](pictures/5-9-5.png)
- 中断让 CPU 不用一直死等某个事件，可以先去干别的事，事件来了再处理，大大提高了效率。
- STM32 的中断由 NVIC（嵌套向量中断控制器）统一管理，它负责给每个中断源分配优先级，高优先级的中断可以打断低优先级的中断，从而实现嵌套。
- 使用中断时要注意：中断服务函数要尽量短，避免影响主程序的实时性；要注意共享变量的保护，防止主程序和中断同时读写造成数据出错。

### 5.10 STM32启动流程
- STM32 上电或复位后，并不是立刻就开始执行我们写的 `main` 函数，中间还有一段初始化的过程，这段过程就叫做启动流程。 \
![图5-10-1 STM32启动流程](pictures/5-10-1.png)
- 启动流程大致如下：首先芯片从固定的地址取出复位后的第一条指令，这个地址里存放的是复位向量，它指向启动文件。
- 启动文件（通常是 `startup_xxx.s`）是用汇编写的，它主要做几件事：初始化堆栈指针 SP，把程序计数器 PC 指向复位处理函数，并设置好中断向量表。
- 接着进入复位处理函数，调用 `SystemInit` 配置系统时钟（也就是前面说的时钟树），然后跳转到 C 库的启动代码。
- C 启动代码负责把已初始化的全局变量从 Flash 拷贝到 RAM、把未初始化的全局变量所在的内存清零（也就是 `.data` 和 `.bss` 段的初始化），最后才调用我们写的 `main` 函数。
- 所以 `main` 函数里可以直接使用全局变量，正是因为在这之前启动代码已经帮我们把它们初始化好了。
